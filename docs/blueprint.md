# **App Name**: Beetlehead Designs Portfolio

## Core Features:

- Artwork Gallery: Display a responsive masonry/grid gallery of character art.
- Image Viewer: Lightbox functionality for viewing full-size images.
- About Section: Display artist bio, profile picture, pronouns, location, and fun facts ('I love bugs 🐛').
- Events Schedule: List upcoming convention appearances (Dublin Horror Con, DCAF 2025, MegaCon 2026, CEILICON 2026, ANTHROCON 2026).
- Shop Links: Provide links to external shops (Etsy, Redbubble) with relevant icons.
- Contact Information: Include contact form or links to social media/email.
- Category filtering: Provide a way to filter art in gallery view to the category being 'Mascots', 'Character Design', 'Convention Work', or 'Customer Photos'.

## Style Guidelines:

- Background color: Dark gray (#222222) to allow the colorful artwork to pop.
- Primary color: Vibrant purple (#B15CD8) for interactive elements like links and buttons, echoing the artist's branding.
- Accent color: Hot pink (#F7347A) to draw attention to key actions and highlight important information.
- Headline font: 'Belleza' (sans-serif) for titles and headings, complementing an artistic flair.
- Body font: 'Alegreya' (serif) for a professional but personal touch in the About section and other text-heavy areas.
- Use custom, playful icons related to social media and shop links.
- Implement a sticky navigation bar for easy access to different sections of the site.
- Subtle animations on image hover effects for engagement.
